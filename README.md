# Employee Attrition Analysis Dashboard (Power BI)

## Project Overview

This project focuses on analyzing employee attrition using the IBM HR Analytics dataset containing information about 1,470 employees.

The dashboard helps HR teams understand employee turnover patterns and identify factors associated with higher attrition rates. It provides interactive visualizations to explore attrition based on department, age group, marital status, satisfaction level, tenure, overtime, and gender.

## Objectives

- Analyze overall employee attrition patterns.
- Identify departments with higher attrition rates.
- Understand attrition trends across different age groups.
- Analyze the relationship between overtime and employee attrition.
- Explore attrition based on marital status, satisfaction level, and tenure.
- Build an interactive dashboard to support data-driven HR decisions.

## Dataset

- **Source:** IBM HR Analytics
- **Total Records:** 1,470 employees
- **Attrition Count:** 237

## Dashboard Analysis

The dashboard analyzes employee attrition across multiple categories:

- Department-wise Attrition
- Age Group-wise Attrition
- Marital Status-wise Attrition
- Satisfaction Level-wise Attrition
- Tenure-wise Attrition
- Overtime-wise Attrition
- Gender-wise Attrition

## Key Insights

- Employees aged 18–25 have the highest attrition rate (35.77%).
- Employees working overtime have a higher attrition rate (30.53%) compared to those not working overtime (10.44%).
- Employees with 0–2 years of tenure have the highest attrition rate (29.82%).
- Single employees have the highest attrition rate (25.53%) among marital status groups.
- The Sales department has the highest attrition rate (20.63%), followed by Human Resources (19.05%).

## Dashboard Features

- Interactive KPI cards.
- Department and gender dropdown filters.
- Job-role selection buttons.
- Multiple visualizations for employee attrition analysis.
